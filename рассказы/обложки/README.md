# Обложки серии «Орбит-фронтальный переход»

Формат 4:5, 640×800 — как посты в канале «Прагматик». Стиль повторяет приёмы канала:
тёмное полотно, цветная утечка (лайм / синий / фиолет), моно-строка `[ метка ]` слева
и `/ Глава NN` справа, заголовок построчно на белых и лаймовых плашках, кадр врезкой,
✦ в лаймовом квадрате внизу.

## Сборка

```
python3 build_covers.py              # HTML всех глав в out/
python3 build_covers.py --png        # плюс PNG (headless Chrome, 2x)
python3 build_covers.py --png --only 1 2 8
```

Данные глав — `covers.json`: номер, слаг, строки заголовка с типом плашки
(`w` — белая, `l` — лаймовая) и хук — одна фраза из рассказа. Подпись под кадром
подтягивается из фронтматтера главы на сайте (поле `story.concept`), руками не дублируется.

## Картинки

Кадр главы кладётся в `img/NN.jpg` (4:5 или шире, кроп по центру). Пока файла нет —
рисуется пунктирная заглушка, вёрстка не ломается, всё остальное собирается.

Промты для Higgsfield — `higgsfield_промты.md`. **MCP higgsfield работает только из папки
`Хигсхилд/`** (OAuth, ключа в реестре нет), из репозитория Системы он не виден.

## Черновики

`_черновики/` — три первых направления (кадр в рамке, диаграмма, тёмный плакат).
Диаграмма из варианта B переехала на сайт: теперь это врезка «Механизм» в конце каждой главы.
